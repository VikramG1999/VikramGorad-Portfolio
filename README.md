# Vikram Gorad - Professional Portfolio

A responsive React application built to showcase my web development projects and technical skills.

## 🔗 Project Links
- **Live Website:** https://VikramG1999.github.io/VikramGorad-Portfolio/
- **GitHub Repository:** https://github.com/VikramG1999/VikramGorad-Portfolio

## 🛠️ Features & Sections
- **About Me**: Brief introduction to my background and goals.
- **Projects**: Portfolio of work including Movie and Recipe apps.
- **Skills**: Technical stack overview including HTML, CSS, JavaScript, and React.
- **Resume**: Section with a download link for professional credentials.
- **Contact**: Direct contact information and email.
- **Responsive Design**: Optimized for mobile, tablet, and desktop using CSS.

## 💻 Tech Stack
- **Frontend**: React.js
- **Build Tool**: Vite
- **Styling**: Custom CSS (Flexbox & Grid)
- **Hosting**: GitHub Pages

## 🚀 Deployment Process
1. **Build**: Generated a production build using `npm run build`.
2. **Hosting**: Deployed via `gh-pages` to GitHub's servers.
3. **Security**: SSL/HTTPS enabled for secure browsing.

## ⚠️ Challenges & Solutions
- **Challenge**: Initial deployment showed a blank page.
- **Solution**: Corrected the `base` path in `vite.config.js` to match the repository name.
