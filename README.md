# Vikram Gorad - Professional Portfolio

A responsive React application built to showcase my web development projects and technical skills.

## 🔗 Project Links
- **Live Website:** [https://VikramG1999.github.io/VikramGorad-Portfolio/](https://VikramG1999.github.io/VikramGorad-Portfolio/)
- **GitHub Repository:** [https://github.com/VikramG1999/VikramGorad-Portfolio](https://github.com/VikramG1999/VikramGorad-Portfolio)

## 🛠️ Features & Sections
- **About Me**: Brief introduction to my background and goals[cite: 1].
- **Projects**: Portfolio of work including Movie and Recipe apps[cite: 7].
- **Skills**: Technical stack overview including HTML, CSS, JavaScript, and React[cite: 9].
- **Resume**: Section with a download link for professional credentials[cite: 8].
- **Contact**: Direct contact information and email[cite: 4].
- **Responsive Design**: Optimized for mobile, tablet, and desktop using CSS Media Queries[cite: 2].

## 💻 Tech Stack
- **Frontend**: React.js (Component-based architecture)[cite: 3].
- **Build Tool**: Vite (Optimized for fast production builds)[cite: 5].
- **Styling**: Custom CSS (Flexbox, Gradients, and Card Layouts)[cite: 2].
- **Hosting**: GitHub Pages.

## 🚀 Development & Deployment Process
1. **Environment**: Set up the project using Vite for high performance[cite: 5, 10].
2. **Components**: Created modular JSX files for each section of the site[cite: 1, 3, 6].
3. **Build**: Generated a production-ready build using `npm run build`[cite: 5, 10].
4. **Hosting**: Utilized the `gh-pages` package to automate deployment from the `dist` folder.

## ⚠️ Challenges & Solutions
- **Challenge**: The deployment initially showed a blank page.
- **Solution**: I configured the `base` path in `vite.config.js` and ensured the `homepage` in `package.json` correctly matched the repository URL.
